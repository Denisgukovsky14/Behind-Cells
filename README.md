# Behind CELLS

**2D пошаговая стратегия с видом 2.5D в стиле тёмного фентези.**

## Об игре
Вы управляете персонажем на сетке. Каждый ваш ход — враг делает свой. Цель: обойти или ранить врага, попав в охраняемый им люк. На первых уровнях атаковать нельзя — только просчитывать пути.

**Сейчас доступно:** 3 начальных уровня.

## Особенности
- **Вариативность** — несколько путей решения каждого уровня.
- **Атмосфера** — тёмное фентези, сеттинг феодальной Японии.
- **Челлендж** — нужно думать и просчитывать ходы наперёд.

## Монетизация
Внутриигровые «монеты подземелий» (подсказки, бонусы, второй шанс, пропуск уровней) + реклама.
